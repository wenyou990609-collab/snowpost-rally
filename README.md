# 雪镇夺礼

[打开浏览器试玩](https://wenyou990609-collab.github.io/snowpost-rally/)

在雪地集市中央抢到礼盒，送回己方仓库得一分。莓红队的仓库在西北，冰蓝队在东南。单人打开时由电脑陪练。

## 两人联机

1. 两人各自在浏览器打开试玩网址。
2. 房主点「邀请好友」和「创建双人房间」，复制完整邀请链接发给好友。
3. 好友打开邀请链接，点「加入好友对战」，将页面生成的回执发回房主。
4. 房主粘贴回执，点「连接好友」。两边显示「好友对战」后即可开玩。

两端通过 WebRTC 直接连接，游玩期间请保持网页在前台。部分网络会限制直连。

## 操作

WASD 移动，鼠标转向，左键疾跑，左 Shift 冲刺，右键坚守，空格放冲击波。按住 Q 回望，Esc 释放鼠标，滚轮调整远近。碰到礼盒自动拾取，进入本队仓库圆圈即可交付。

本仓库包含网页版试玩构建，使用 Godot 引擎。引擎及第三方组件的许可见 [NOTICE.txt](NOTICE.txt)。
