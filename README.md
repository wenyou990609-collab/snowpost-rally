# 雪镇夺礼

[打开浏览器试玩](https://wenyou990609-collab.github.io/snowpost-rally/?v=online2)

在雪地集市中央抢到礼盒，送回己方仓库得一分。莓红队的仓库在西北，冰蓝队在东南。单人打开时由电脑陪练。

## 两人联机

1. 一人点「邀请好友」和「创建双人房间」，把完整房间链接发给另一人。
2. 好友在浏览器打开邀请链接，会自动加入。两边的顶部显示「好友对战」后即可开玩。

已经拿到房间链接时，两人直接打开同一条链接即可。先进入的是莓红队，后进入的是冰蓝队。双方各自通过公网 WebSocket 中继同步操作和对局状态，可以使用不同网络。游戏期间请保持页面在前台，一人退出后本局结束。[中继服务说明](https://ittysockets.com/)

## 操作

WASD 移动，鼠标转向，左键疾跑，左 Shift 冲刺，右键坚守，空格放冲击波。按住 Q 回望，Esc 释放鼠标，滚轮调整远近。碰到礼盒自动拾取，进入本队仓库圆圈即可交付。

本仓库包含网页版试玩构建，使用 Godot 引擎。引擎及第三方组件的许可见 [NOTICE.txt](NOTICE.txt)。
